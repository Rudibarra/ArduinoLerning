# Arduino Learning Wokwi

A small starter repo for learning Arduino with the Wokwi simulator extension.

## First sketch

`sketch.ino` blinks the built-in LED on an Arduino Uno and writes status messages to the serial monitor.

## How to use

1. Open this folder in VS Code.
2. Make sure the Wokwi extension is installed.
3. Open `diagram.json` or `sketch.ino`.
4. Start the Wokwi simulation.

## Files

- `sketch.ino` - Arduino code.
- `diagram.json` - Wokwi virtual circuit.
- `wokwi.toml` - Wokwi project configuration.
